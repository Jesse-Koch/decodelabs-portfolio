# Project 4: Data Visualisation

**DecodeLabs Industrial Training Kit**

9-slide dashboard built from the e-commerce dataset analyzed in Projects 1–3.

---

## Deliverable

A 9-slide PowerPoint dashboard.

---

## Design Principles Applied

### Architect
- Chart type matched to business question
- No 3D effects, no distortion

### Editor
- Maximized data-ink ratio
- No gridlines, borders, or chartjunk
- Direct labeling (no legends)
- Color as spotlight: 1 blue + greys

### Storyteller
- Action titles state the conclusion (not the topic)
- One slide = one message
- Every chart answers "So what?"
